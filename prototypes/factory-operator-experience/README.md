# Prototipo Factory Operator Experience

Workspace descartable, Inbox-first, para revisar las cinco Missions Open del fixture. La interfaz no usa servicios externos: carga datos locales y todas las acciones son simulaciones en la memoria del navegador, sin efectos externos.

```sh
cd prototypes/factory-operator-experience
npm run self-check
npm run prototype
```

Abrir <http://127.0.0.1:4316>. Detener el servidor con `Ctrl+C`.
